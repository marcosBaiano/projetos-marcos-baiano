## Organização

- Projetos PHP foram separados por finalidade e versão.
- Projetos Laravel foram isolados de exercicios e bancos auxiliares.
- Projetos React e frontend foram publicados sem dependências locais.
- ZIPs, arquivos `.dat`, dumps `.sql`, logs e ambientes `.env` não foram publicados.
- Dependências como `node_modules`, `vendor`, `.venv`, IDEs e arquivos temporários foram excluídas.
